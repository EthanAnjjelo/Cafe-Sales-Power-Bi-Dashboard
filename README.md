# Cafe-Sales-Power-Bi-Dashboard
Interactive Power BI sales &amp; revenue dashboard analyzing cafe transactional data, product margins, and customer preferences.
## Overview
I put together this project to practice end-to-end data visualization and dashboard design using a simulated cafe dataset. The goal was to build a clean, executive-ready report that highlights key financial metrics—like revenue, cost, and profit margins—while allowing users to slice data by category, time, and payment method.

## Key Features & Metrics
* **KPI Summary Cards:** High-level metrics tracking Total Revenue, Total Profit, Profit Margin, Total Orders, and Average Order Value.
* **Sales Trends:** Line charts showing revenue performance over time.
* **Product Performance:** Clustered bar charts identifying top-selling items and categories.
* **Payment & Order Breakdown:** Donut charts analyzing customer payment preferences and order types (Dine-in vs. Takeaway).
* **Interactive Slicers:** Date range and category filters for dynamic data exploration.

## Tech Stack & Tools
* **Power BI Desktop:** Report authoring, data modeling, and visualization.
* **DAX:** Calculated measures for revenue, cost, and profit margins.
* **Microsoft Excel:** Raw sample dataset storage and structuring (`Cafe_Sales_Sample_Cleaned.xlsx`).
